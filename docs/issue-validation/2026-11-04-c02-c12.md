# C02 cancellation / C12 supported role management

- C02 keeps **Đã đăng ký**. When the API advertises canCancelRegistration and a valid own registration version, clicking opens a confirmation modal naming the activity. Keep/dismiss sends no request. Confirm uses stable idempotency/current registration version; errors retain registration; duplicate/stale-account responses are guarded. Only a matching successful cancellation receipt changes local state, then authoritative detail/history/schedule data is reloaded. Permitted registration can be repeated with a new operation key.
- API cancels only the authenticated user's current registration, before activity start and before any attendance exists. It preserves the participant row as cancelled, filters inactive registrations from existing EF reads, releases/reconciles the seat counter atomically and reuses the row on a subsequent valid registration. Idempotency receipts retain prior cancellation confirmations; attendance/staff/evidence rows are not deleted or awarded/refunded XP. No arbitrary userId cancellation payload is accepted.
